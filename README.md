# Open Datasets

Six open datasets published by Moe Kahok alongside the studies at [Wagopedia](https://wagopedia.com), [MyElderHome](https://myelderhome.com), and [MoveNoble](https://movenoble.com). Each folder contains the exact CSV data behind the published study plus a README with sources, column definitions, and citation details.

All datasets are licensed **CC BY 4.0** — free to reuse with attribution to the publisher named in each folder's README.

## Sources

- Pet insurance: NAPHIA 2026 industry data.
- Shelter lifesaving: Best Friends Animal Society 2025 state rankings.
- Older-adult falls: CDC NCHS Data Brief 532 (2023 mortality data).
- Care costs: CareScout Cost of Care Survey 2025.
- Migration (datasets 5–6): IRS Statistics of Income (SOI) migration data, 2022–2023.
