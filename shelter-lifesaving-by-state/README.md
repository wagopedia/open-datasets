# Shelter Lifesaving by State, 2025

**Author:** Moe Kahok (Wagopedia)

## Description

Best Friends Animal Society's 2025 shelter-lifesaving rankings for all 50 states and the District of Columbia: each state's no-kill gap (the additional dogs and cats that would need to be saved for every shelter in the state to reach a 90% save rate), its share of the national gap, whether the state is already no-kill statewide, and its 2025 save rate where published. The national save rate is 82.5%; Texas alone accounts for 78,800 animals of the gap (19.9%), while Delaware, New Hampshire, Rhode Island, and Vermont are already no-kill.

## Data file

- `shelter-lifesaving-by-state-2025.csv` — 51 rows (50 states + District of Columbia), ranked closest to no-kill first: rank, state, additional pets to save to reach no-kill, gap value used for ranking, whether the gap is an upper bound, share of U.S. gap (%), no-kill statewide flag, 2025 save rate, save-rate source, source note.

## Source

Best Friends Animal Society, 2025 state rankings and state data releases (released April 2026).
